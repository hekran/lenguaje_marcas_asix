VScode

VScode es un IDE, gratuito y desarrollado por Microsoft

VScode fue anunciado en 2015, es más útil que un editor de texto plano, ya que ayuda mucho a la productividad, tiene autocompletado de etiquetas html, así como "Word Wrap" que se puede activar y desactivar pulsando ALT+Z

VScode no fue el 1o, pero es de los más completos actualmente y de los más fáciles de utilizar, además de muy potente debido a su integración con GIT y el uso de plugins

No solo sirve para html o CSS, sirve para un gran número de lenguajes de programación como por ejemplo Python, aquí un ejemplo de código que se podría escribir en VScode
