Esto es un CSS en archivo externo

El CSS externo consiste en vincular un archivo independiente con extensión .css al documento HTML mediante la etiqueta <link> ubicada dentro de la sección <head>. Esta es la práctica más recomendada en el desarrollo web moderno, ya que logra una separación total entre la estructura del sitio y la capa de diseño. Al cargar una sola hoja de estilos vinculada, es posible controlar la apariencia gráfica de cientos o miles de páginas web simultáneamente desde un único archivo centralizado.

Entre sus principales ventajas destacan la optimización del rendimiento y la facilidad de mantenimiento. Los navegadores web almacenan en caché el archivo CSS externo tras la primera carga, lo que reduce drásticamente el consumo de ancho de banda y acelera el tiempo de respuesta en las visitas posteriores. Además, cuando es necesario realizar un cambio de diseño o corregir un error visual, basta con modificar el archivo de estilos centralizado para que los cambios se reflejen al instante en todo el sitio web.
