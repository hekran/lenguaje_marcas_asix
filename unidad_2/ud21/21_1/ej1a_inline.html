Esto es un CSS inline

El CSS inline (o en línea) consiste en aplicar estilos directamente a un elemento HTML específico mediante el atributo style. A diferencia de las hojas de estilo externas o los bloques <style>, las reglas se escriben justo dentro de la etiqueta de apertura (por ejemplo, <p style="color: blue;">), lo que les otorga el nivel más alto de prioridad en la cascada de CSS. Esta especificidad máxima permite sobreescribir prácticamente cualquier otro estilo previo sin necesidad de recurrir a reglas adicionales.

A pesar de su practicidad para realizar pruebas rápidas, correcciones puntuales o aplicar dinámicamente estilos mediante JavaScript, su uso continuado no es aconsejable en proyectos grandes. Utilizar CSS inline rompe el principio de separación de responsabilidades entre el contenido (HTML) y la presentación (CSS), dificulta el mantenimiento del código al no permitir la reutilización de reglas y aumenta el tamaño de los archivos. Además, limita el uso de características avanzadas como pseudo-clases (:hover), pseudo-elementos o reglas @media para diseño adaptativo.
