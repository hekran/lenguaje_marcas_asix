Esto es un CSS style en head

El uso de CSS interno mediante la etiqueta <style> dentro de la sección <head> permite definir todas las reglas de estilo de una página web en un único lugar centralizado. A diferencia del CSS inline, este enfoque evita la repetición de código al permitir que una sola regla se aplique a múltiples elementos del mismo documento a través de selectores de etiquetas, clases o identificadores. Resulta especialmente útil para páginas individuales, prototipos rápidos o correos electrónicos HTML que requieren un diseño personalizado sin necesidad de gestionar archivos externos.

Sin embargo, incluir los estilos en la cabecera presenta ciertas limitaciones en proyectos de gran escala. Dado que los estilos definidos en el <head> solo afectan al documento HTML en el que se encuentran, no es posible reutilizarlos en otras páginas de un sitio web, lo que obliga a duplicar código y complica el mantenimiento. Para proyectos web multipágina, la práctica recomendada sigue siendo vincular una hoja de estilo externa mediante la etiqueta <link>, reservando el bloque <style> para casos muy puntuales o estilos específicos de una sola página.
